## 우리가 지켜야 할 포지션

`오늘의 결 카드`는 단순 점괘 앱이 아니라, 한국 역사 인물 오라클을 기반으로 한 `리딩 저널 + 상담 전환` 서비스다.

핵심 전략:

- 무료 리딩으로 진입
- 저장/히스토리로 재방문 유도
- 반복 카드/주제/감정 흐름으로 리포트 가치 생성
- 깊은 해석과 상담 연결로 수익화

## 경쟁 앱 유형

### 1. 콘텐츠형 운세 앱

대표:

- 포스텔러
- 점신

강점:

- 무료/유료 콘텐츠 양이 많음
- 오늘의 운세, 신년운세, 연애운, 재물운 등 즉답감이 강함
- 유저가 고민 없이 눌러볼 메뉴가 많음
- 매년 신년운세 시즌에 강함

약점:

- 자기 기록과 장기 패턴 분석은 약함
- 개인의 질문 맥락을 깊게 누적하는 구조는 약함
- 콘텐츠가 많아도 사용자가 자기 이야기를 남기는 공간은 제한적

우리 보완 방향:

- 단순 콘텐츠 수량 경쟁은 피한다.
- 대신 `나의 기록에서 나온 리포트`를 강점으로 만든다.
- 주제별 콘텐츠 패키지는 만들되, 질문/저널/리포트와 묶는다.

### 2. 상담 연결형 앱

대표:

- 홍카페
- 천명
- 타로문
- Sanctuary

강점:

- 전화/채팅/보이스/화상 상담 연결
- 24시간 상담 가능
- 상담사 후기와 프로필 기반 신뢰
- 연애, 재회, 속마음, 진로, 금전처럼 결제 욕구가 강한 주제에 집중

약점:

- 상담 전 단계에서 사용자의 생각을 정리해주는 도구는 약함
- 불안한 순간의 즉시 결제에 기대기 쉬움
- 상담 전후 기록이 제품 자산으로 쌓이는 구조가 약할 수 있음

우리 보완 방향:

- 상담 전 `리딩 기록 요약`을 제공한다.
- 같은 주제가 반복될 때 상담 CTA를 노출한다.
- 상담은 예언 보강이 아니라 `기록 기반 정리`로 포지셔닝한다.

### 3. 저널/학습형 타로 앱

대표:

- Labyrinthos
- Biddy Tarot
- CHANI

강점:

- 카드 의미 학습
- 저널 저장
- 리딩 기록
- 반복 카드/슈트 분석
- 세계관과 디자인 완성도
- 유료 덱, 프리미엄 해석, 커뮤니티로 확장 가능

약점:

- 한국어/한국 문화 맥락이 약함
- 한국 사용자가 바로 결제할 만한 상담 연결은 약함
- 인물 서사 기반의 현지화된 오라클 경험은 부족함

우리 보완 방향:

- `한국 역사 인물 + 타로 원형 + 상담 질문`을 고유 자산으로 만든다.
- 78장 심화 해설집을 핵심 유료 콘텐츠로 삼는다.
- 카드 디자인을 덱 상품으로 확장한다.

## 우리가 당장 따라가야 할 것

1. Labyrinthos식 저널/리포트
   - 저장 기록 수
   - 반복 카드
   - 반복 주제
   - 감정 흐름
   - 월간 리포트

2. 포스텔러식 콘텐츠 패키지
   - 관계 거리 두기 14일
   - 돈과 안정 루틴 21일
   - 오래된 고민 정리 노트
   - 신년/월간 리딩 패키지

3. 홍카페/천명식 상담 신뢰 구조
   - 상담사 프로필
   - 후기
   - 상담 가능 시간
   - 가격
   - 비밀보장
   - 환불/취소 정책
