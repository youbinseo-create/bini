# Symbol Layer System

작성일: 2026-05-13

사용자 아이디어:

```text
기존 타로 카드의 상징을 왼쪽 아래에 넣고,
역사 인물과 관련된 상징물을 오른쪽에 넣어서,
상징을 추가 해석할 수 있게 만들면 어떨까?
```

## 결론

이 아이디어는 매우 좋다. 선현 카드가 단순히 "잘생긴 역사 인물 카드"로 끝나지 않고, 실제 리딩 도구가 되려면 카드 안에 해석 가능한 상징 레이어가 필요하다.

이 구조를 쓰면 카드 한 장이 세 겹으로 읽힌다.

```text
1. 기존 타로 상징
2. 한국 역사/선현 상징
3. 인물의 태도와 시선
```

이렇게 하면 사용자에게는 익숙한 타로 리딩의 안정감이 생기고, 동시에 우리 덱만의 한국적 차별화도 생긴다.

## 카드 레이아웃 규칙

### 왼쪽 아래: 기존 타로 상징

역할:

- 기존 타로 사용자에게 익숙한 해석 기준을 제공한다.
- 카드의 기본 의미를 빠르게 읽게 한다.
- 웹앱 리딩에서 해설 구조를 만들기 쉽다.

예시:

```text
The Fool: 흰 개, 작은 보따리, 절벽, 흰 꽃
The Magician: 지팡이, 컵, 검, 펜타클 또는 네 도구
The High Priestess: 달, 장막, 두 기둥, 책
The Emperor: 왕좌, 산, 붉은 옷, 권위의 상징
The Hermit: 등불, 지팡이, 산길
Wheel of Fortune: 바퀴, 사방의 상징, 운명의 회전
Justice: 저울, 검
The Star: 별, 물, 두 그릇
```

주의:

- 너무 원본 타로처럼 베끼면 안 된다.
- 상징은 작은 아이콘처럼 넣되, 한국적 재료로 변환한다.
- 예: 저울은 청동 저울, 등불은 한지 등, 장막은 비단 발, 책은 빈 두루마리로 바꾼다.

### 오른쪽: 역사 인물 관련 상징

역할:

- 이 카드가 왜 이 인물인지 설명한다.
- 한국적 차별성을 만든다.
- 카드별 해설을 깊게 만든다.

예시:

```text
세종/창제: 문자 조각, 책, 측우기, 해시계, 별, 집현전 문서
정도전/설계: 도성 설계도, 나침반, 자, 붓, 지도, 북두칠성
이순신/결단: 거북선, 바다, 북, 칼, 깃발
허준/치유: 약재, 침통, 약탕기, 의서, 산초/풀잎
신사임당/섬세함: 초충도, 붓, 포도, 나비, 풀꽃
정약용/개혁: 책, 수레, 기계 장치, 목민심서 상징, 다리
김홍도/관찰: 붓, 사람들, 풍속 장면, 부채
황진이/매혹: 거문고, 달, 매화, 비단, 시
장영실/발명: 해시계, 물시계, 별자리, 금속 장치
```

주의:

- 실제 텍스트를 이미지 안에 넣지 않는 것이 안전하다.
- AI가 한글/한자를 망가뜨리기 때문에, 글자는 나중에 인쇄/웹 레이아웃에서 얹는다.
- 상징물은 오른쪽에 크게 하나, 작게 둘 정도가 적당하다.

### 중앙: 매력적인 인물

역할:

- 첫눈 후킹
- 상담받고 싶은 신뢰감
- 소장욕

사용자 기준:

```text
사람이 잘생기고 매력적이어야 한다.
```

이 기준은 필수다. 선현 카드가 역사 교육 자료처럼 보이면 안 된다. 보고 싶고, 조언을 듣고 싶고, 소장하고 싶은 인물이어야 한다.

## 추천 카드 구조

```text
상단: 카드 번호 또는 덱 심볼
중앙: 매력적인 선현/상징 인물
왼쪽 아래: 기존 타로에서 온 핵심 상징
오른쪽: 역사 인물 고유 상징
네 귀퉁이: 작고 반복 가능한 보조 상징
하단: 카드명/키워드 영역
배경: 나전/한지/비단/궁궐/자연 요소
```

## 네 귀퉁이 상징 시스템

사용자 추가 아이디어:

```text
4면의 귀퉁이에 각각 상징을 추가하면 좋다.
```

이 아이디어도 좋다. 네 귀퉁이는 카드 전체의 해석 프레임을 잡아준다. 다만 귀퉁이 상징은 작고 규칙적이어야 한다. 중앙 인물보다 튀면 안 된다.

### 역할

```text
왼쪽 위: 질문의 출발점
오른쪽 위: 하늘/운명/방향
왼쪽 아래: 기존 타로 핵심 상징
오른쪽 아래: 현실에서의 행동 또는 결과
```

이렇게 두면 사용자가 카드를 읽을 때 시선 흐름이 생긴다.

```text
왼쪽 위 → 오른쪽 위 → 중앙 인물 → 왼쪽 아래 → 오른쪽 상징 → 오른쪽 아래
```

### 기본 귀퉁이 세트

선현 덱 전체에 공통으로 쓰기 좋은 귀퉁이 상징:

```text
왼쪽 위: 작은 별 또는 질문의 씨앗
오른쪽 위: 북두칠성 또는 달
왼쪽 아래: 카드별 타로 상징
오른쪽 아래: 봉인, 인장, 씨앗, 길, 문 중 하나
```

의미:

- 왼쪽 위: 지금 묻는 질문
- 오른쪽 위: 큰 흐름과 운명
- 왼쪽 아래: 기존 타로 문법
- 오른쪽 아래: 현실로 가져갈 실천

### 속성별 귀퉁이 상징

카드마다 속성을 나누면 해설이 더 깊어진다.

```text
불: 등불, 해, 붉은 매듭, 봉황 깃
물: 잔, 물결, 연꽃, 달항아리
바람: 새, 부채, 구름, 펼친 두루마리
흙: 산, 돌, 책, 기와, 소나무
빛: 자개 조각, 별, 거울, 금선
그림자: 가면, 먹, 문, 검은 곡선
```

### 인생 영역별 귀퉁이 상징

사용자 리딩에서 돈이 되는 영역과 연결하기 좋다.

```text
관계: 붉은 실, 두 잔, 새 한 쌍
진로: 나침반, 길, 지도
재물: 곡식, 엽전, 창고 문
학업/창작: 붓, 벼루, 책, 빈 종이
마음 회복: 연꽃, 물, 달, 학
경계/결단: 칼, 저울, 문턱, 산
```

### 선현 카드 전용 귀퉁이 구조

선현 덱은 아래 구조가 가장 좋다.

```text
왼쪽 위: 질문 영역 상징
오른쪽 위: 천명/방향 상징
왼쪽 아래: 기존 타로 상징
오른쪽 아래: 선현의 실천 상징
```

예:

창제 카드:

```text
왼쪽 위: 작은 별과 빈 종이
오른쪽 위: 북두칠성
왼쪽 아래: 마법사의 네 도구를 한국식으로 변환한 붓/벼루/두루마리/측우기
오른쪽 아래: 문자 조각이 아니라 빛나는 자개 조각 또는 인장
```

설계 카드:

```text
왼쪽 위: 지도 위의 점
오른쪽 위: 나침반 별
왼쪽 아래: 황제/정의 계열의 저울과 자
오른쪽 아래: 기단 돌 또는 성문
```

인연 카드:

```text
왼쪽 위: 두 개의 작은 별
오른쪽 위: 달과 구름
왼쪽 아래: 두 잔과 붉은 실
오른쪽 아래: 연꽃 봉오리
```

직언 카드:

```text
왼쪽 위: 먹 한 방울
오른쪽 위: 곧은 별빛
왼쪽 아래: 검과 저울
오른쪽 아래: 봉인된 상소문
```

### 디자인 주의

귀퉁이 상징은 "작은 아이콘"처럼 써야 한다.

하지 말 것:

- 네 귀퉁이에 큰 그림을 넣기
- 중앙 인물 얼굴과 경쟁하기
- 상징마다 색을 다르게 해서 산만하게 만들기
- 읽을 수 없는 가짜 글자 넣기

해야 할 것:

- 금선, 자개, 먹선으로 작게 처리
- 같은 크기와 같은 위치 유지
- 카드별로 의미만 바꾸고 형식은 통일
- 인쇄 시 잘 보이는 단순 실루엣 사용

## 전체 상징 밀도 규칙

한 카드에 들어갈 상징 수는 아래 정도가 적당하다.

```text
중앙 인물: 1
왼쪽 아래 타로 상징: 1~2
오른쪽 역사 상징: 1~3
네 귀퉁이 상징: 4
배경 보조 상징: 1~2
```

총 8~12개 정도지만, 실제로 눈에 크게 들어오는 것은 3개 이하여야 한다.

중요도 순서:

```text
1. 인물 얼굴과 눈빛
2. 카드 고유 역사 상징
3. 기존 타로 상징
4. 네 귀퉁이 보조 상징
5. 배경 장식
```

## 예시 설계

### 창제 카드

인물:

```text
세종 계열의 젊고 지적인 왕/학자형 인물
```

왼쪽 아래 타로 상징:

```text
The Magician 계열의 네 도구를 한국식으로 변환
붓, 벼루, 빈 두루마리, 측우기 또는 해시계
```

오른쪽 역사 상징:

```text
빛나는 문자 조각, 집현전 문서, 별자리, 책
```

해석:

```text
생각을 언어로 만드는 힘.
질문을 구조화하고, 사람들과 소통 가능한 형태로 바꾸는 카드.
```

### 설계 카드

인물:

```text
정도전 계열의 지적인 설계자/전략가
```

왼쪽 아래 타로 상징:

```text
The Emperor 또는 Justice 계열
청동 저울, 자, 단단한 돌 기단
```

오른쪽 역사 상징:

```text
도성 설계도, 나침반, 북두칠성, 붓
```

해석:

```text
감정이 아니라 구조로 문제를 해결하는 힘.
새 질서를 세우는 결단.
```

### 인연 카드

인물:

```text
의상 계열의 따뜻한 스승/수행자
```

왼쪽 아래 타로 상징:

```text
The Lovers 또는 Two of Cups 계열
두 잔, 붉은 실, 마주 보는 작은 새
```

오른쪽 역사 상징:

```text
연꽃, 사찰, 법계, 이어지는 금실
```

해석:

```text
관계는 소유가 아니라 연결이다.
화합, 발원, 조화의 카드.
```

### 직언 카드

인물:

```text
조식 계열의 강직한 충언자
```

왼쪽 아래 타로 상징:

```text
Justice 계열
검, 저울, 곧은 선
```

오른쪽 역사 상징:

```text
상소문, 붓, 관청의 문, 산처럼 단단한 배경
```

해석:

```text
불편한 진실을 말해야 할 때.
침묵보다 정직이 필요한 순간.
```

## 장점

### 1. 기존 타로 사용자에게 낯설지 않다

완전히 새 덱이면 사용자가 해석법을 배우기 어렵다. 왼쪽 아래에 익숙한 타로 상징이 있으면 기본 해석의 발판이 생긴다.

### 2. 한국적 차별화가 강해진다

오른쪽 상징은 선현과 한국 문화에서 온다. 그래서 단순 한국풍 코스튬 카드가 아니라 한국적 지혜 카드가 된다.

### 3. AI 리딩과 잘 맞는다

해설을 세 부분으로 나눌 수 있다.

```text
타로 상징 해석
역사 인물 상징 해석
현재 질문에 대한 조언
```

이 구조는 웹앱/AI 상담 기능에 매우 좋다.

### 4. 카드별 깊이가 생긴다

사용자가 불만을 말했던 "무슨 카드를 뽑아도 작은 행동을 하라" 같은 얕은 해석을 피할 수 있다. 카드마다 상징 조합이 달라지기 때문이다.

## 위험

### 1. 화면이 복잡해질 수 있다

상징을 너무 많이 넣으면 고급 카드가 아니라 설명 이미지가 된다.

해결:

```text
왼쪽 아래 타로 상징 1~2개
오른쪽 역사 상징 1~3개
중앙 인물은 반드시 가장 중요하게
```

### 2. 타로 표절처럼 보일 수 있다

기존 웨이트 타로 이미지를 그대로 베끼면 안 된다.

해결:

```text
상징의 의미만 가져오고, 형태는 한국식 물건으로 변환한다.
```

### 3. 인물 매력이 죽을 수 있다

상징물이 많아지면 인물이 배경처럼 밀릴 수 있다.

해결:

```text
인물 얼굴, 눈빛, 자세가 1순위.
상징물은 해석을 돕는 보조 장치.
```

- 왼쪽 아래 타로 도구 상징이 원형 문장처럼 더 명확해졌다.
- 오른쪽 아래 실천/매듭 상징도 별도 문장처럼 읽힌다.
- 카드 하단의 좌우 상징이 해석용 장치로 보이기 시작했다.

남은 문제:

- 오른쪽 아래 인장 안에 글자처럼 보이는 질감이 있다.
- 최종판에서는 인장을 무문양 봉인, 씨앗, 자개 점, 금선 문양으로 바꾸는 것이 안전하다.

다음 프롬프트 수정:

```text
Lower-right emblem must not contain seals with writing-like marks. Use a plain blank seal, seed, sprouting leaf, crimson knot, and mother-of-pearl dots only. No engraved marks, no stamp characters, no square glyphs.
```

- 오른쪽의 지도/설계/나침반 상징이 카드 의미와 맞다.

## 현재 판단

이 구조는 선현 덱을 한 단계 올릴 수 있다.

현재 가장 좋은 방향:

```text
선현 인물 매력
+ 왼쪽 아래 기존 타로 상징
+ 오른쪽 한국 역사 상징
+ 나전/한지/금선의 고급 물성
```

이렇게 가면 단순히 잘생긴 인물 카드가 아니라, 실제로 리딩 가능한 프리미엄 한국 오라클 카드가 된다.
