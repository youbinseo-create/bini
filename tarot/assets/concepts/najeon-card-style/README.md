# Najeon Card Style

나전칠기와 자개를 카드 뒷면, 박스, 패키지, 리워드 가격감으로 발전시키는 폴더다.

## Files

```text
style-alt-modern-minimal-a.png
```

초기 자개 미니멀 스타일. 고급스럽고 깔끔하지만, 나전칠기의 공예 구조보다는 자개 텍스처를 얹은 느낌이 강하다.

```text
najeon-packaging-c2.png
```

나전칠기 패키지 강화 버전. 흑칠 바탕, 자개 조각, 국화당초문, 진주점 테두리, 금속선이 살아 있어 카드 뒷면과 박스 리워드에 적합하다.

```text
najeon-symbolic-c3.png
```

초기 미니멀 자개 버전의 밝고 아름다운 감성을 회복하면서, 붉은 실, 컵, 가면이라는 카드 상징을 더 분명히 넣은 버전. 현재 나전 계열에서는 가장 강한 후보.

```text
najeon-tumblbug-hero-c4.png
```

C3 방향을 텀블벅 첫 제품 컷으로 확장한 버전. 카드 3장, 박스, 가이드북, 실물 리워드 느낌이 같이 보여 펀딩 상세페이지 첫 구간에 적합하다.

```text
najeon-red-thread-closeup-c5.png
```

붉은 실 카드 단독 정면컷. 현재까지 나온 단일 카드 후보 중 소장욕과 상징성이 가장 강하다. 상세페이지, SNS, 대표 카드 설명에 쓰기 좋다.
