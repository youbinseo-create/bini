## Current Judgment

사용자는 사람이 잘생기고 매력적이어야 한다고 강조했다. 이 기준은 매우 중요하다.

현재 최선 방향:

```text
S6의 인물 매력 + 하단 메달리온 구조 + 글자 없는 기하학 자개 배경
```

현재 확장 평가:

```text
창제 S6: 기준 카드
설계 S1: 바로 후보급
인연 S1: 대중성과 아름다움 좋음
직언 S1: 상징은 좋지만 톤이 무거워 S2 필요
치유 S1: 부드러운 힐링 카드로 후보 유지
결단 S1: 방향성과 상업성 좋아 후보 유지
관찰 S1: 상징은 좋지만 배경 밝기 보완 후보
```

## Next Prompt Direction

다음 버전은 인물을 더 매력적으로 유지하되, 너무 웹소설/아이돌 캐릭터처럼 가지 않게 해야 한다.

핵심:

- 잘생기고 매력적인 얼굴
- 상담받고 싶은 눈빛
- 역사적 품격
- 한국적 복식의 신뢰감
- 과하지 않은 나전 장식
- 왼쪽 아래 타로 상징, 오른쪽 역사 상징, 네 귀퉁이 보조 상징
- 텍스트는 이미지 안에 넣지 않기
- letter-like fragments도 금지하고, 자개 조각/별빛/추상 문양으로 대체하기
- 하단 양쪽 상징은 원형 메달리온/문장처럼 명확하게 만들기
- 인장 안쪽에도 글자 느낌을 넣지 않기
