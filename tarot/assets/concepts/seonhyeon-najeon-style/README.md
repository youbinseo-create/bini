## Next Prompt Direction

다음 버전은 인물을 더 매력적으로 유지하되, 너무 웹소설/아이돌 캐릭터처럼 가지 않게 해야 한다.

핵심:

- 잘생기고 매력적인 얼굴
- 상담받고 싶은 눈빛
- 역사적 품격
- 한국적 복식의 신뢰감
- 과하지 않은 나전 장식
- 왼쪽 아래 타로 상징, 오른쪽 역사 상징, 네 귀퉁이 보조 상징
- 텍스트는 이미지 안에 넣지 않기
- letter-like fragments도 금지하고, 자개 조각/별빛/추상 문양으로 대체하기
