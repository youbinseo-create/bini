# Concept Image History

이 폴더는 텀블벅 카드덱 이미지 생성 히스토리를 보관한다. 실패작도 삭제하지 않는다. 이유는 이미지의 매력, 펀딩 가능성, 프롬프트 개선 방향을 비교하기 위해서다.

## 보관 원칙

- 생성 이미지는 원본 기본 저장소에도 남기고, 프로젝트 안에는 후보 이름으로 복사한다.
- 앱에 바로 연결하는 이미지는 `tarot/assets/cards`에 둔다.
- 펀딩, 상세페이지, 스타일 실험 이미지는 이 폴더에 둔다.
- 실패한 이미지도 삭제하지 않고 왜 약했는지 기록한다.
- 새 이미지는 날짜와 버전 또는 목적이 드러나는 이름으로 저장한다.

## 현재 이미지

### tumblbug-hero-v0-dark.png

첫 번째 텀블벅 히어로 실험.

판정:

- 장점: 신비감, 어두운 의식감.
- 단점: 너무 어둡고 불길해 보임. 자기성찰/펀딩 첫 컷으로는 부담스러움.
- 사용처: 반면교사. 어둠을 줄여야 한다는 기준.

### tumblbug-hero-v0-bright.png

두 번째 밝은 히어로 실험.

판정:

- 장점: 밝고 부드러워짐. 선물용/힐링 덱 느낌.
- 단점: 배경이 평범하고 인물이 흔한 일러스트처럼 보임.
- 사용처: 밝기와 접근성 기준.

### tumblbug-hero-luxury-v0.png

세 번째 화보형 럭셔리 실험.

판정:

- 장점: 자개, 금박, 비단, 박스 등 소장 욕구 요소가 늘어남.
- 단점: 뒷모습과 전신 구도가 반복됨. 인물 매력이 약함.
- 사용처: 패키지/후가공 질감 기준.

### tumblbug-hero-character-v1.png

네 번째 캐릭터 개선 실험.

판정:

- 장점: 얼굴, 손, 감정 공간으로 카드별 구도가 분리됨. 이전보다 펀딩 대표컷에 가까움.
- 단점: 왼쪽 인물이 아직 일반 K-판타지 미인 화보처럼 보일 위험이 있음. 오른쪽 카드는 컵과 상실 구조가 더 선명해야 함.
- 사용처: 현재 기준 후보. 다음 생성의 기준점.

## 다음 개선 방향

- 얼굴 카드는 더 독자적인 한국적 상징을 넣는다.
- 손/사물 카드는 상징을 더 크게, 더 명확히 잡는다.
- 감정 카드는 컵 개수와 감정 구조가 한눈에 읽히게 한다.
- 배경은 화려하되 카드보다 더 튀지 않게 조정한다.
