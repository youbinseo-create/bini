minhwa-folding-screen-b5.png

병풍과 고급 민화의 질감을 더 살린 버전. B4보다 진중하고 전통 회화 느낌이 강해졌지만, 즉시 구매욕은 나전 C4/C5보다 약하다.

## Next

현재 판단은 B5가 B4보다 전통 회화감은 낫지만, 메인 상품 축으로는 아직 나전 계열보다 약하다. 민화는 별도 라인 또는 보조 테마로 유지하고, 메인은 나전 C4/C5 방향이 더 강하다.
