# Tumblbug Reward Plan

작성일: 2026-05-13

목표: 카드덱 펀딩의 리워드 가격과 구성을 현실적으로 정리한다.

## 기본 전략

처음부터 고가 세트에 의존하지 않는다. 먼저 낮은 진입 장벽으로 후원자를 모으고, 실물 카드덱 중심으로 객단가를 만든다.

기존 핵심 리워드:

```text
32,000원 얼리버드 카드덱
38,000원 일반 카드덱
49,000원 카드덱 + 디지털 해설서 + 웹앱 베타 초대
69,000원 카드덱 + 종이 미니 해설서 + 보관 파우치
```

제작비 모델 검토 후 수정 권장 리워드:

```text
34,000원 얼리버드 카드덱
42,000원 일반 카드덱
52,000원 카드덱 + 디지털 해설서 + 웹앱 베타 초대
72,000원 프리미엄 소장 세트
```

이유:

- 현재 이미지 방향은 저가 카드보다 프리미엄 소장 덱에 가깝다.
- 32,000원/38,000원은 하드박스, 금박, 해설서, 배송비를 넣으면 마진이 위험할 수 있다.
- 정확한 가격은 인쇄 견적 후 확정한다.

## 목표금액

추천 목표:

```text
3,000,000원
```

이유:

- 달성률이 높아 보이면 텀블벅에서 신뢰가 올라간다.
- 첫 프로젝트라면 너무 높은 목표보다 빠른 달성이 유리하다.
- 수백만 원 펀딩을 목표로 하되, 목표금액 자체는 낮게 잡고 초과 달성을 노린다.

## 리워드 구성안

### 1,000원 응원 후원

구성:

- 모바일 배경화면 3종
- 감사 메시지

역할:

- 가벼운 응원 유입
- SNS 팔로워/지인 참여용

### 9,900원 디지털 미니 가이드북

구성:

- 대표 카드 10장 PDF
- 카드별 질문 3개
- 자기성찰 기록 페이지

역할:

- 실물 카드 구매 전 테스트
- 제작비 부담이 낮은 디지털 리워드

### 34,000원 얼리버드 카드덱

구성:

- 카드덱 1개
- 디지털 미니 가이드북

역할:

- 핵심 전환 리워드
- 한정 수량 권장

### 42,000원 일반 카드덱

구성:

- 카드덱 1개
- 디지털 미니 가이드북

역할:

- 기본 리워드

### 52,000원 카드덱 + 웹앱 베타

구성:

- 카드덱 1개
- 디지털 해설서
- 웹앱 베타 초대
- 후원자 전용 리딩 기록 템플릿

역할:

- 실물 펀딩과 웹앱 확장을 연결
- 프로젝트의 장기성을 보여줌

### 72,000원 프리미엄 세트

구성:

- 카드덱 1개
- 종이 미니 해설서
- 보관 파우치
- 디지털 해설서
- 웹앱 베타 초대

역할:

- 객단가 상승
- 선물용/소장용 후원자 타깃

### 99,000원 2개 세트

구성:

- 카드덱 2개
- 디지털 해설서
- 웹앱 베타 초대 2개

역할:

- 친구/연인/선물 수요
- 배송비 효율

### 149,000원 리딩 리포트 세트

구성:

- 카드덱 1개
- 디지털 해설서
- 웹앱 베타 초대
- 1:1 리딩 리포트 1회

역할:

- 상담/리포트 수익화 테스트
- 수량 제한 필수

권장 수량:

```text
10~20개 제한
```

## 주의할 점

- 종이 해설서는 제작비가 크므로 처음부터 과하게 약속하지 않는다.
- 파우치/박스/후가공은 샘플 제작 후 확정한다.
- 149,000원 리포트 세트는 운영 리소스가 들기 때문에 수량 제한한다.
- 배송비, 포장비, 불량 교환 비용을 반드시 계산해야 한다.
- 목표금액 300만원 기준으로 실제 제작비가 맞는지 인쇄 견적을 받아야 한다.

## 추천 메인 리워드

초기 페이지에서는 아래 3개를 가장 눈에 띄게 배치한다.

```text
34,000원 얼리버드 카드덱
52,000원 카드덱 + 웹앱 베타
72,000원 프리미엄 소장 세트
```

이유:

- 32,000원은 결제 장벽이 낮다.
- 49,000원은 앱 확장성을 보여준다.
- 69,000원은 소장욕과 선물 수요를 잡는다.
