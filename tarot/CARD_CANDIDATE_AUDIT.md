# Card Candidate Audit

Created: 2026-05-15

Scope:

```text
Audit current generated Seonhyeon/Najeon card candidates for:
1. Face appeal
2. Korean costume/setting authenticity
3. Bottom symbol clarity
```

## Current Verdict

The deck is improving, but it is not final-master ready.

Strongest progress:

```text
Faces are much more attractive and memorable than the early drafts.
The fixed 1024 x 1536 deck frame is working.
Jangin S1 proves the Korean najeon/craft identity can be much stronger than generic palace fantasy.
```

Main problems:

```text
1. Some costumes still drift toward Chinese hanfu / wuxia / generic East Asian fantasy.
2. Bottom medallions are too cluttered.
3. Many lower symbols are small scenic still lifes instead of one readable symbol.
```

## Bottom Symbol Rule

User critique:

```text
아래 상징이 소재 한개만 되는데 너무 배경과 잡다한 요소가 있는건 아닌지 확인해줘.
```

This critique is correct.

New rule:

```text
Each bottom medallion should use one primary object only.
Optional support: one line, one glow, or one tiny secondary accent.
Do not make a miniature background scene inside the medallion.
```

Allowed:

```text
single cup
single mirror
single compass
single lantern
single bojagi
single najeon shell piece
single sword in sheath
single red thread knot
single moon jar
single flower
```

Avoid:

```text
landscape inside medallion
room scene inside medallion
multiple props arranged like a product still life
tiny gates, tables, roads, mountains, bowls, cloths, and tools together
background architecture inside medallion
```

Why:

```text
Tarot symbols must be read quickly.
If the medallion becomes a miniature illustration, the meaning becomes decorative instead of symbolic.
```
