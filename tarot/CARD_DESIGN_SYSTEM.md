# 오늘의 결 카드 디자인 시스템

## 방향

`오늘의 결 카드`는 한국 역사 인물의 서사를 타로 원형과 연결한 성찰형 오라클 덱이다.
무속적 공포감보다 `궁중 기록화 + 현대 판타지 오라클` 톤을 기준으로 한다.

## 카드 앞면 원칙

- 상단: 카드 번호, 타로 대응, 슈트
- 중앙: 텍스트 없는 인물 장면 일러스트
- 하단: 인물명, 한국어 카드명, 핵심 키워드 3개
- 카드 내부 긴 문장 금지
- 한글 텍스트는 이미지 생성 결과물에 넣지 않고, 디자인 레이어나 앱 UI에서 합성

## 비주얼 톤

- 질감: 한지, 먹 번짐, 금박 테두리, 오래된 지도
- 인물: 실제 초상 재현보다 상징적 인물화
- 배경: 한국 산수, 궁궐, 서원, 바다, 장터, 전장, 서책, 달빛
- 분위기: 신비롭지만 과장되지 않게, 상담/저널 앱에 어울리는 차분함

## 슈트별 색상

- 큰 길: 흑금, 백색, 깊은 청색
- 행동의 불길: 적색, 금색, 검정
- 마음의 물길: 청록, 남색, 은색
- 생각의 칼길: 백색, 회색, 먹색
- 삶을 짓는 흙길: 녹갈색, 황토, 옥색

## 제작 파일 기준

```text
master: 2048x3072 이상 PNG
app: 720x1234 WebP 또는 JPG
thumbnail: 360x617 WebP 또는 JPG
ratio: 7:12 세로 카드 비율
```

권장 파일명:

```text
00_the-fool_hyecho_master.png
00_app.webp
00_thumb.webp
```

## 검수 체크리스트

- 손, 얼굴, 눈, 장신구 왜곡 확인
- 이미지 안에 깨진 글자가 없는지 확인
- 슈트별 색상과 전체 덱 톤이 맞는지 확인
- 인물의 법적/윤리적 리스크 확인
- 현대 인물은 실사 초상 재현을 피하고 상징적 장면으로 표현
- 앱용 이미지와 마스터 이미지를 분리 보관

## 카드 데이터와 연결

각 카드의 `visualPrompt`는 이미지 제작 초안이다.
최종 제작 시에는 이 프롬프트를 그대로 쓰기보다 카드별 역사 장면과 상징을 보강해 사용한다.

## 제작 단계

카드 이미지는 한 번에 완성본으로 만들기보다 단계로 관리한다. 이유는 78장을 동시에 만들면 톤, 해상도, 파일명, 카드 의미가 쉽게 흔들리기 때문이다.

```text
0_missing: 아직 이미지 없음
1_placeholder: 임시 이미지 또는 낮은 품질 이미지
2_draft: 앱에서 표시 가능한 초안
3_app_ready: 앱 배포용으로 톤과 크기 정리 완료
4_master_ready: 고해상도 원본 보관 완료
5_print_ready: 인쇄/굿즈 제작까지 고려한 최종본
```

현재 상태는 `2_draft`에 가까운 카드가 28장, `0_missing` 카드가 50장이다. 즉, 앱은 보여줄 수 있지만 “돈을 받을 수 있는 덱”은 아직 아니다.

## 제작 우선순위

우선순위는 앱에서 자주 보이고, 리딩의 인상을 크게 좌우하고, 향후 상담/유료 리포트로 연결하기 좋은 카드부터 잡는다.

1. 메이저 아르카나 누락 카드
2. 연애, 진로, 돈, 자기이해 질문에서 자주 쓰일 카드
3. 상담 전환에 강한 카드
4. 나머지 마이너 아르카나

1차 보강 후보:

```text
01_magician
02_high-priestess
04_emperor
08_strength
12_hanged-man
13_death
15_devil
17_star
19_sun
20_judgement
```

상담/리포트 전환 핵심 후보:

```text
07_chariot
13_death
40_five-of-cups
57_eight-of-swords
64_ace-of-pentacles
```

## 이미지 프롬프트 원칙

- 카드 안에는 글자, 한글, 숫자, 로고를 넣지 않는다.
- 인물은 실존 인물을 그대로 닮게 만들기보다 상징적 장면으로 표현한다.
- 표정은 과장하지 않고, “결정 직전의 정적”을 기본 감정으로 둔다.
- 배경은 한국적 사물과 공간을 쓰되 민속풍 장식만으로 끝내지 않는다.
- 카드별 의미가 한눈에 읽히는 중심 사물을 반드시 하나 둔다.
- 해외 프리미엄 덱처럼 작게 봐도 읽히는 실루엣을 먼저 설계한다.
- 국내 상담앱처럼 질문 카테고리와 연결될 수 있는 감정 장면을 만든다.

예시:

```text
not "타로 카드에 세종대왕 글자 넣기"
yes "조용한 밤, 펼쳐진 책상 위 문자 조각과 등불, 창밖 새벽빛"
```

## 앱 표시 원칙

앱에서는 카드 이미지가 리딩을 압도하면 안 된다. 카드는 “문을 여는 물건”이고, 해석과 기록이 사용자를 붙잡는 핵심이다.

- 결과 화면 카드 이미지는 모바일 기준 화면 높이의 절반을 넘기지 않는다.
- 리딩 본문이 카드 아래로 너무 밀리면 이미지를 줄인다.
- 카드 선택 화면에서는 뒷면이 먼저 보여야 한다.
- 뽑은 뒤에는 카드 이미지, 한 줄 답, 깊은 해석, 기록 순서로 읽히게 한다.
- 유료 리포트/상담 CTA는 결과 직후보다 저장 또는 반복 패턴 확인 뒤에 배치한다.

## 리서치 반영

자세한 경쟁 카드 디자인 분석은 `CARD_DESIGN_RESEARCH.md`를 기준 문서로 둔다.

핵심 반영점:

- Labyrinthos/Golden Thread: 카드 이미지를 앱 장식이 아니라 브랜드 상품으로 본다.
- Biddy Tarot: 초보자가 무서워하지 않는 부드럽고 접근 가능한 색을 쓴다.
- Modern Witch Tarot: 전통 상징을 현대 생활의 장면으로 번역한다.
- Tarot of the Divine: 카드마다 문화적 이야기와 companion content를 붙인다.
- 국내 운세/상담 앱: 이미지만으로는 부족하고, 고민 카테고리와 상담 전환이 함께 있어야 한다.
