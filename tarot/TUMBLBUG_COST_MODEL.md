# Tumblbug Cost Model

작성일: 2026-05-13

목표: 카드덱 펀딩 가격이 실제로 남는 구조인지 계산하기 위한 기준표다. 아직 실제 인쇄 견적을 받은 것이 아니므로, 이 문서는 `가설 모델`이다.

## 확인한 외부 기준

### 텀블벅 수수료

공식 헬프센터 기준:

- Start 요금제 플랫폼 수수료: 총 결제 성공 금액의 5%, VAT 별도
- 결제 등 대행 수수료: 총 결제 금액의 3%, VAT 별도

계산상 기본 수수료:

```text
플랫폼 5% + 결제대행 3% = 8%
VAT 별도 -> 8.8%로 가정
```

즉 38,000원 리워드가 결제되면, 텀블벅 수수료만 대략 3,344원 정도로 본다.

```text
38,000원 x 8.8% = 3,344원
```

### 타로덱 인쇄 비용 변수

인쇄 업체 자료 기준으로 타로덱 단가는 아래 요소에 따라 크게 달라진다.

- 주문 수량: 100~300개 소량은 단가가 높고, 500~1000개 이상은 단가가 낮아짐
- 카드 수: 78장 풀덱은 44장 오라클보다 비쌈
- 카드 크기: 일반 타로 크기 70x120mm 또는 88x126mm 계열
- 용지: 300gsm, 350gsm, 400gsm, 블랙코어/블루코어 여부
- 마감: 무광, 유광, 소프트터치, 린넨 등
- 후가공: 금박, 홀로그램박, 엣지 컬러/금박
- 박스: 턱박스, 2단 하드박스, 자석 박스
- 가이드북: 흑백/컬러, 8/16/32페이지, 제본 방식

## 비용 항목

카드덱 1개당 봐야 할 비용:

```text
카드 인쇄비
박스 제작비
해설서 제작비
후가공비
포장재
배송비
불량/교환 예비비
텀블벅 수수료
부가세/세무 처리 여지
```

## 단가 시나리오

정확한 견적 전까지 아래 3단계로 본다.

### 보수적 MVP 사양

구성:

- 78장 카드
- 기본 박스
- 디지털 해설서
- 최소 후가공

예상 제작 원가:

```text
카드/박스/포장: 13,000~18,000원
국내 배송/포장: 3,500~4,500원
불량/예비비: 1,000~2,000원
합계: 17,500~24,500원
```

### 프리미엄 기본 사양

구성:

- 78장 카드
- 하드 박스
- 디지털 해설서
- 금박 또는 엣지 컬러 일부

예상 제작 원가:

```text
카드/박스/후가공/포장: 20,000~28,000원
국내 배송/포장: 3,500~5,000원
불량/예비비: 2,000~3,000원
합계: 25,500~36,000원
```

### 프리미엄 풀 사양

구성:

- 78장 카드
- 하드 박스 또는 자석 박스
- 종이 미니 해설서
- 금박/자개 느낌 박/엣지 컬러
- 파우치

예상 제작 원가:

```text
카드/박스/후가공/해설서/파우치/포장: 32,000~45,000원
국내 배송/포장: 4,000~6,000원
불량/예비비: 3,000~5,000원
합계: 39,000~56,000원
```

## 리워드별 손익 가설

수수료는 Start 요금제 기준 8.8%로 계산한다.

### 32,000원 얼리버드

```text
후원가: 32,000원
텀블벅 수수료 8.8%: 2,816원
수수료 차감 후: 29,184원
```

판정:

- MVP 사양이면 가능.
- 프리미엄 사양이면 위험.
- 하드박스/금박/종이 해설서까지 넣으면 거의 남지 않음.

권장:

```text
32,000원 얼리버드는 수량 제한 + 디지털 해설서 중심으로만 운영.
```

### 38,000원 일반 카드덱

```text
후원가: 38,000원
텀블벅 수수료 8.8%: 3,344원
수수료 차감 후: 34,656원
```

판정:

- MVP 사양은 가능.
- 프리미엄 기본 사양은 아슬아슬.
- 배송비 포함 구조라면 마진이 많이 줄어듦.

권장:

```text
일반 카드덱 가격은 38,000원보다 42,000~45,000원 검토 필요.
```

### 49,000원 카드덱 + 웹앱 베타

```text
후원가: 49,000원
텀블벅 수수료 8.8%: 4,312원
수수료 차감 후: 44,688원
```

판정:

- 프리미엄 기본 사양까지 가능성이 있음.
- 웹앱 베타는 물리 원가가 낮기 때문에 가치 추가에 좋음.
- 핵심 메인 리워드로 적합.

권장:

```text
49,000원 세트를 메인 리워드로 밀어도 좋음.
```

### 69,000원 프리미엄 소장 세트

```text
후원가: 69,000원
텀블벅 수수료 8.8%: 6,072원
수수료 차감 후: 62,928원
```

판정:

- 종이 해설서/파우치/후가공을 넣을 여지가 있음.
- 그래도 풀 사양 원가가 50,000원 이상이면 남는 폭이 작음.

권장:

```text
69,000원 세트는 수량 제한 또는 구성 엄격 관리.
파우치와 종이 해설서는 견적 확인 후 확정.
```

### 99,000원 2개 세트

```text
후원가: 99,000원
텀블벅 수수료 8.8%: 8,712원
수수료 차감 후: 90,288원
```

판정:

- 카드덱 2개 기준 1개당 실수령 45,144원.
- 배송비 효율이 좋아질 수 있음.
- 선물용 수요에 적합.

권장:

```text
일반 카드덱 단가를 42,000~45,000원으로 올린다면 2개 세트 79,000~85,000원도 검토 가능.
99,000원은 프리미엄 구성 포함 시 적합.
```

### 149,000원 리딩 리포트 세트

```text
후원가: 149,000원
텀블벅 수수료 8.8%: 13,112원
수수료 차감 후: 135,888원
```

판정:

- 물리 원가보다 운영 시간이 핵심 비용.
- 1:1 리포트를 직접 작성해야 하므로 수량 제한 필수.

권장:

```text
10개 이하로 시작.
리포트 분량, 제공일, 환불 기준을 명확히 고지.
```

## 현재 가격안 수정 제안

기존:

```text
32,000원 얼리버드
38,000원 일반
49,000원 앱 베타 세트
69,000원 프리미엄 세트
```

수정 권장:

```text
34,000원 얼리버드 카드덱
42,000원 일반 카드덱
52,000원 카드덱 + 디지털 해설서 + 웹앱 베타
72,000원 프리미엄 소장 세트
```

이유:

- 32,000원/38,000원은 예쁘고 프리미엄한 실물 이미지를 보여주는 현재 방향과 마진이 맞지 않을 수 있다.
- 사용자는 V8/V9/V11 수준의 이미지를 보면 프리미엄을 기대한다.
- 가격을 너무 낮게 잡으면 후가공과 박스 품질을 낮춰야 해서 브랜드가 무너질 수 있다.

## 반드시 받아야 할 견적

인쇄 업체에 아래 조건으로 견적 요청한다.

```text
수량: 300 / 500 / 1000개
카드 수: 78장
카드 크기: 70x120mm, 88x126mm 각각
용지: 350gsm / 400gsm / 블랙코어
인쇄: 양면 풀컬러
마감: 무광 / 소프트터치
엣지: 일반 / 금박 / 컬러 엣지
박스: 턱박스 / 2단 하드박스 / 자석박스
가이드북: 없음 / 16p 흑백 / 32p 컬러
포장: 개별 수축포장 여부
납기: 샘플 제작 기간 / 본 생산 기간
불량 교환 조건
```

## 손익분기점 예시

목표금액 3,000,000원 기준.

평균 후원가 49,000원이라면:

```text
3,000,000 / 49,000 = 약 62명
```

평균 후원가 42,000원이라면:

```text
3,000,000 / 42,000 = 약 72명
```

하지만 실제 제작 수량은 최소 인쇄 수량 때문에 300개 이상이 될 수 있다. 따라서 목표금액 300만원은 “펀딩 성공 표시”에는 좋지만, 실제 제작비 전체를 감당하기엔 부족할 수 있다.

현실적 운영 목표:

```text
1차 성공 표시 목표: 3,000,000원
실제 안정 제작 목표: 10,000,000원 이상
확장 목표: 20,000,000원 이상
```

## 결론

현재 이미지 퀄리티는 낮은 가격 상품보다 프리미엄 카드덱에 가깝다. 그래서 가격을 너무 낮게 잡으면 오히려 위험하다.

추천 전략:

```text
목표금액은 낮게 300만원
메인 리워드는 42,000~52,000원 구간
프리미엄 세트는 72,000원 이상
상담/리포트 세트는 소량 고가 테스트
실제 가격 확정은 인쇄 견적 후
```
