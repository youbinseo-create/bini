# Style Comparison Plan

작성일: 2026-05-13

현재 메인 후보는 밝은 화보형 프리미엄 오라클 스타일이다. 하지만 최종 선택 전에는 전혀 다른 스타일 후보를 최소 2개 더 만들어 비교한다.

## 비교할 스타일

### Style 1. 밝은 화보형 프리미엄 오라클

대표 이미지:

```text
tumblbug-hero-visualart-v8.png
tumblbug-card-red-thread-v9.png
```

특징:

- 화사하고 고급스러움
- 소장욕 강함
- 붉은 실 카드가 강한 후킹
- 텀블벅 첫 컷 후보로 가장 앞서 있음

위험:

- 장식이 많아 AI 판타지/웨딩 화보처럼 보일 수 있음
- 인쇄/후가공 비용이 높아질 가능성

### Style 2. 현대 미니멀 자개 오라클

목표:

- 더 현대적이고 디자인 상품처럼 보이는 방향
- 여백, 자개, 얇은 금박, 상징 중심
- 고급 문구/라이프스타일 굿즈 느낌

검증할 것:

- 너무 차분해서 텀블벅 후킹이 약하지 않은가
- 소장욕은 있는가
- 카드별 의미가 충분히 읽히는가

### Style 3. 민화 팝 오라클

목표:

- 더 밝고 대중적인 한국적 감성
- 민화, 보자기 색, 달항아리, 까치, 구름, 꽃
- 선물용/굿즈용 확장 가능성

검증할 것:

- 너무 귀엽거나 가벼워 보이지 않는가
- 프리미엄 가격을 받을 수 있는가
- 자기성찰 도구로 깊이가 느껴지는가

## 평가 기준

각 스타일은 아래 기준으로 비교한다.

```text
1. 텀블벅 썸네일 멈춤력
2. 소장욕
3. 밝고 긍정적인 첫인상
4. 카드별 상징 가독성
5. 한국적 정체성
6. 프리미엄 가격 설득력
7. 제작 난이도/비용 리스크
8. 웹앱 확장성
```

## 현재 가설

```text
가장 유력: Style 1 밝은 화보형 프리미엄 오라클
비교 필요: Style 2 현대 미니멀 자개 오라클
비교 필요: Style 3 민화 팝 오라클
```

최종 선택은 이미지 생성 후 다시 검증한다.

## 생성 결과

### Style 2 결과

파일:

```text
tarot/assets/concepts/najeon-card-style/style-alt-modern-minimal-a.png
```

판정:

- 매우 현대적이고 세련됨.
- 자개, 여백, 얇은 금박, 상징 중심이라 디자인 오브젝트 느낌이 좋음.
- 제작/리터칭 난이도가 낮고 브랜드 시스템화하기 쉬움.
- 다만 텀블벅 썸네일에서 즉시 “와 예쁘다”는 후킹은 V8보다 약함.
- 프리미엄 문구/갤러리 굿즈/라이프스타일 브랜드 방향에 적합.

### Style 3 결과

파일:

```text
tarot/assets/concepts/minhwa-card-style/style-alt-minhwa-pop-b.png
```

판정:

- 밝고 대중적이며 접근성이 좋음.
- 민화, 보자기 색, 까치, 달항아리, 꽃 요소가 즉시 읽힘.
- 선물용/굿즈용으로 확장하기 좋음.
- 다만 프리미엄 카드덱보다는 캐주얼 일러스트 굿즈에 가까워질 위험이 있음.
- 자기성찰의 깊이보다 귀엽고 밝은 인상이 먼저 올 수 있음.

## 비교표

```text
Style 1 밝은 화보형 프리미엄: 소장욕 최강, 펀딩 첫 컷 유력, 제작 난이도 높음
Style 2 현대 미니멀 자개: 브랜드화 쉬움, 고급 문구 느낌, 후킹은 약함
Style 3 민화 팝: 대중성/선물용 좋음, 프리미엄 깊이는 약할 수 있음
```

## 현재 추천

메인 덱은 Style 1을 유지한다.

이유:

- 현재 사용자의 목표인 “화보 같고 소장욕구 뿜뿜”에 가장 가깝다.
- V8/V9가 이미 강한 감정 훅을 만든다.
- 텀블벅에서 프리미엄 가격을 설득하기 가장 좋다.

보조 활용:

- Style 2는 카드 뒷면, 박스, 웹앱 UI, 해설서 디자인 참고로 활용한다.
- Style 3는 추후 캐주얼 확장팩, SNS 굿즈, 입문자용 카드팩으로 활용 가능하다.

## 민화 스타일 추가 리서치

현재 `style-alt-minhwa-pop-b.png`는 밝고 귀엽지만, 진짜 민화의 디자인 힘을 충분히 쓰지는 못했다.

민화에서 더 가져와야 할 요소:

- 호작도: 까치와 호랑이, 권위에 대한 해학과 풍자
- 책거리/책가도: 책, 문방구, 도자기, 기물의 평면적 배열
- 문자도: 글자와 그림이 결합되는 구조. 단, 카드 이미지 안에는 실제 글자를 넣지 않고 추상 문양으로 변환
- 화조도: 꽃과 새, 부부/조화/기쁨/번영 상징
- 모란도: 부귀와 화려함
- 십장생도: 해, 달, 구름, 산, 물, 학, 거북, 사슴, 소나무, 불로초
- 초충도: 작은 꽃과 곤충의 섬세함
- 오방색: 청, 적, 황, 백, 흑의 상징적 색 체계

민화 디자인 원칙:

- 원근법보다 평면 구성
- 사실성보다 상징성
- 예쁜 비례보다 일부러 어긋난 해학
- 밝은 색, 굵은 윤곽, 반복 패턴
- 부적처럼 기원을 담는 이미지
- 집 안에 걸어두고 복을 비는 생활 미술 감각

다음 민화 버전 목표:

```text
민화 느낌을 얹은 타로가 아니라,
민화의 구조로 다시 만든 오라클 카드.
```

검증 질문:

- 호작도/책거리/화조도/십장생 구조가 실제로 보이는가
- 한국적 정체성이 장식이 아니라 카드 구조가 되었는가
- 현대 텀블벅 후원자가 “이건 완전 다르다”고 느끼는가
- 너무 아동용처럼 가볍지는 않은가

## 최신 후보 판단

2026-05-13 추가 생성 후 판단:

```text
민화 B5: tarot/assets/concepts/minhwa-card-style/minhwa-folding-screen-b5.png
나전 C4: tarot/assets/concepts/najeon-card-style/najeon-tumblbug-hero-c4.png
나전 C5: tarot/assets/concepts/najeon-card-style/najeon-red-thread-closeup-c5.png
```

현재 가장 강한 방향은 나전 C4/C5다.

이유:

- C4는 카드, 박스, 가이드북, 실물 리워드가 같이 보여 텀블벅 첫 제품 증거 컷으로 좋다.
- C5는 단일 카드의 소장욕과 상징성이 가장 강하다.
- 민화 B5는 B3/B4보다 고급 민화 느낌이 좋아졌지만, 아직 대표 상품으로 즉시 사고 싶게 만드는 힘은 나전보다 약하다.

따라서 다음 제작 기준은 다음과 같다.

```text
대표 카드 단독컷 기준: najeon-red-thread-closeup-c5.png
펀딩 첫 제품컷 기준: najeon-tumblbug-hero-c4.png
보조/비교 스타일: minhwa-folding-screen-b5.png
```
