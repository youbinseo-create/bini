## 문제 파일

### 1. 비율 확인 필요

```text
0.png
해상도: 1024 x 1536
비율: 0.6667
```

다른 카드 대부분은 약 0.584 비율인데, 이 파일은 2:3에 가깝다. 카드 프레임이나 크롭 기준이 다를 수 있다.

```text
13.png
해상도: 992 x 1586
비율: 0.6255
```

다른 카드보다 비율이 조금 넓다. 인쇄/웹앱 통일 시 좌우 크롭 또는 리사이즈 확인이 필요하다.

### 2. 작거나 저해상도

```text
2.png
해상도: 827 x 1417
비율: 0.5836
```

비율은 맞지만 전체 해상도가 작다. 웹앱 미리보기는 가능하지만, 펀딩 대표 이미지나 인쇄용으로는 리마스터 후보에 넣는 것이 좋다.

### 3. 가로형 파일

```text
ChatGPT Image 2026년 4월 27일 오후 06_22_36.png
해상도: 1402 x 1122
비율: 1.2496
```

가로형이다. 80장 카드 본편에 들어가는 이미지인지, 표지/배경/실패본인지 확인해야 한다.

### 4. 파일명 정리 필요

아래 파일들은 규격은 대체로 맞지만 파일명이 카드 번호 체계가 아니다.

```text
ChatGPT Image 2026년 4월 30일 오전 08_54_16.png
ChatGPT Image 2026년 4월 30일 오전 09_01_24.png
ChatGPT Image 2026년 4월 30일 오전 09_06_42.png
ChatGPT Image 2026년 4월 30일 오전 09_09_43.png
ChatGPT Image 2026년 4월 30일 오전 09_17_13.png
ChatGPT Image 2026년 4월 30일 오전 12_58_47.png
ChatGPT Image 2026년 4월 30일 오후 01_03_21.png
```

이 파일들은 실제 카드명과 번호를 확인한 뒤 `45.png` 같은 번호형으로 바꾸거나, 별도 후보 폴더로 분리해야 한다.

## 샘플 시각 평가

확인한 샘플:

```text
0.png
10.png
21.png
2 (5).png
```

평가:

- 한국 선현/조선 인물 카드라는 정체성이 선명하다.
- 검정/금색 프레임과 인물 중심 구도가 강하다.
- 카드마다 역할 키워드가 보여 상담형 콘텐츠로 확장하기 좋다.
- 나전 라인과는 미감이 완전히 다르므로 하나의 덱에 섞으면 안 된다.

## 상품화 판단

선현 카드는 이미 81장 자산이 있어서 제작 속도 면에서 유리하다. 단, 바로 펀딩에 쓰려면 다음 정리가 필요하다.

1. 80장 본편과 1장 예외 파일 구분
2. 카드 번호와 카드명 확정
3. 중복 번호 후보 정리
4. 텍스트 오류 확인
5. 파일명 통일
6. 웹앱용 저해상도 버전 생성
7. 펀딩 상세페이지용 대표 카드 6~9장 선정

## 추천

선현 라인은 별도 독립 덱으로 진행한다.

나전 라인:

```text
감정, 관계, 회복, 자기성찰 중심의 상징 오라클
```

선현 라인:

```text
인물, 지혜, 질문, 조언, 상담형 오라클
```

두 라인은 서로 다른 상품으로 독립시키는 것이 좋다. 그래야 나전의 고급 감성과 선현의 인물 상담성이 서로 방해하지 않는다.
