# 프리미엄 리딩 스키마

## 목표

무료 리딩은 짧은 성찰을 제공하고, 유료 리딩은 기록을 바탕으로 더 깊은 관점과 상담 준비 질문을 제공한다.
핵심은 불안을 키우는 예언이 아니라, 반복되는 질문과 감정 패턴을 정리하는 것이다.

## 카드별 심화 필드

```json
{
  "archetype": "카드의 심리 원형",
  "historicalScene": "한국 인물 서사의 핵심 장면",
  "coreMeaning": "카드의 중심 의미",
  "light": ["빛 키워드"],
  "shadow": ["그림자 키워드"],
  "love": "관계/연애 해석",
  "work": "일/진로 해석",
  "money": "돈/현실 해석",
  "inner": "내면/자기성찰 해석",
  "questionPrompts": ["상담 질문"],
  "action": "작은 실천",
  "journalPrompt": "저널 질문",
  "premiumNote": "유료 리딩에서 깊게 읽을 지점",
  "visualPrompt": "카드 이미지 제작 프롬프트"
}
```

## 무료 리딩

- 오늘의 메시지
- 카드가 비추는 마음
- 스스로에게 물어볼 질문
- 오늘의 지침
- 리딩 저장
- 최근 기록 일부 보기

## 유료 리딩

- 다른 관점 3가지
- 빛과 그림자 해석
- 주제별 해석: 관계, 일, 돈, 내면
- 상담으로 가져갈 질문
- 저널 프롬프트
- 최근 기록과 연결한 패턴 요약

## 상담 연결 조건

상담 CTA는 결과 직후 강하게 노출하지 않는다.
아래 조건에서 자연스럽게 제안한다.

- 같은 주제를 3회 이상 저장
- 기록이 5개 이상 쌓임
- 사용자가 메모를 남김
- 사용자가 `상담 준비하기`를 누름

## 추천 상품

- 최근 30일 성찰 리포트: 단건 2,900원
- 월간 리포트 구독: 월 4,900원
- 주제별 질문/기록 패키지: 1,900원-4,900원
- 78장 심화 해설집
- 실물 오라클 덱 + 워크북

## 윤리 기준

- 미래를 확정하지 않는다.
- 의료, 법률, 재정 판단을 대신하지 않는다.
- 불안 조장 문구를 쓰지 않는다.
- 상담은 예언 보강이 아니라 생각 정리의 연장으로 배치한다.
