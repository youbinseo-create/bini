# USDT 환차익 대시보드

빗썸/업비트 USDT 호가와 KB국민은행 USD 환율을 가져와 **5,000 USDT 기준 예상 수익**을 계산하는 로컬/배포용 대시보드입니다.

## 주요 기능

- 빗썸, 업비트 `KRW-USDT` 실시간 가격 조회
- 거래소별 호가창 기준 평균 매수가 계산
- KB USD 환율 조회
- 현찰 파실 때 90% 우대, 송금 받을 때 90% 우대, 매매기준율, 수동 환율 선택
- 업비트/빗썸 수수료 분리 입력
- 전송 수수료, 보수적 매수가 버퍼, 고정비 반영
- 기본값: `5,000 USDT`

## 배포

이 앱은 서버에서 외부 API와 KB 환율 페이지를 가져옵니다. 그래서 GitHub Pages 같은 정적 호스팅만으로는 동일하게 동작하지 않습니다.

추천 배포 방식은 Render Web Service입니다.

1. 이 폴더를 GitHub 저장소로 올립니다.
2. Render에서 `New Web Service`를 선택합니다.
3. GitHub 저장소를 연결합니다.
4. 시작 명령은 `node server.mjs`로 둡니다.
5. `render.yaml`이 있으므로 Render가 설정을 자동 인식할 수 있습니다.

Docker가 필요한 환경에서는 `Dockerfile`을 사용할 수 있습니다.

## 계산 원리

```text
예상 순익 =
(KB 적용 환율 × 실제 매도 가능 수량)
- (호가 평균 매수가 × 매수 수량)
- 거래 수수료
- 고정비
```

호가 평균 매수가는 마지막 체결가가 아니라, 거래소 호가창의 매도 호가를 위에서부터 채워 5,000 USDT를 사는 가중평균가입니다.

KB 90% 우대는 은행 스프레드를 90% 줄이는 방식으로 계산합니다.

```text
90% 우대 환율 = 매매기준율 - (매매기준율 - 파실 때 환율) × 10%
```

## 주의

이 도구는 가격 차이를 빠르게 보는 계산기입니다. USDT는 KB에서 직접 매도할 수 있는 USD가 아니므로 실제 현금화 경로가 따로 필요합니다. 실제 수익은 체결가, 호가 잔량, 거래소별 수수료, 출금 네트워크, USDT/USD 괴리, 은행의 실제 적용 환율과 한도에 따라 달라집니다.
